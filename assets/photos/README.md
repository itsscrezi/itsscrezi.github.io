# About photos

Put the image files you want in the About carousel in this folder: `assets/photos/`.

Then open `content.js` and add each relative path to the `aboutPhotos` array. Example:

```js
aboutPhotos: [
  'assets/photos/live-show.jpg',
  'assets/photos/studio.jpg',
  'assets/photos/portrait-02.png'
],
```

Keep the first path as the first image shown. Use JPG, PNG, or WebP. The carousel displays the full image without cropping. Commit the photo files and `content.js` together for them to appear on the website.
